# Этап 2: проход по рубрике

Ниже — рубрика проверок и нормализованный текст ADR. Пройди по КАЖДОМУ пункту рубрики
и вынеси вердикт. Помни железные правила: `pass` только с дословной цитатой; догадки — это
`unclear`; не додумывай за автора.

Вердикты:

- `pass` — в ADR есть явное доказательство (см. поле `evidence` пункта) — процитируй его;
- `fail` — в ADR этого нет или написана отписка без содержания;
- `unclear` — что-то похожее есть, но понять нельзя — процитируй мутное место;
- `n-a` — пункт неприменим по условию `applicability` (объясни почему в `comment`).

Для каждого `fail` и `unclear` сформулируй `question_for_author` — готовый к копипасту
в Confluence вопрос. Для `pass` и `n-a` это поле — пустая строка.

Ответ — один JSON-документ без обёртки, строго такой формы:

```
{
  "items": [
    {
      "id": "<id из рубрики>",
      "title": "<title из рубрики>",
      "severity": "<severity из рубрики>",
      "status": "pass | fail | unclear | n-a",
      "quote": "<дословная цитата из ADR или пустая строка>",
      "comment": "<одно-два предложения: почему такой вердикт>",
      "question_for_author": "<вопрос автору или пустая строка>"
    }
  ]
}
```

Поля `id`, `title`, `severity` копируй из рубрики как есть. В `items` должен быть каждый
пункт рубрики ровно один раз, в порядке рубрики.
